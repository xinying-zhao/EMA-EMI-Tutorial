# 生态瞬时评估（EMA）与生态瞬时干预（EMI）研究指南

欢迎来到 **EMA-EMI-Tutorial** 仓库！本项目旨在为初学者及跨学科研究者提供一个系统、实用的教程，介绍如何在精神心理、公共卫生及人机交互等领域开展 **生态瞬时评估（Ecological Momentary Assessment, EMA）** 和 生态瞬时干预（Ecological Momentary Intervention） 研究。

本教程特别关注 **“隐形”可穿戴设备与 EMA 的结合应用**，以帮助研究者在真实世界中捕获多维度、高频次、情境相关的心理与生理数据。

## 🌟 项目简介

传统诊疗与研究往往依赖于回顾性自评或单次实验室测量，难以捕捉精神心理状态的动态波动。EMA 方法通过在自然环境中高频、实时地收集数据，极大地提升了评估的生态效度（Ecological Validity）。

本项目基于《“隐形”可穿戴设备联合生态瞬时评估方法在精神心理领域中的应用》报告及最新的方法学文献构建，带你走通 EMA 研究的全流程规范。

> **特别说明**：虽然 EMA 技术广泛适用于慢性病管理、工作场所压力评估、健康行为干预等多个学科，但为了便于读者理解具体的操作逻辑与病理机制，本指南在各章节中将**重点采用精神心理领域（如抑郁症、精神分裂症、社交焦虑等）的真实临床案例**进行深入剖析。

## 🚀 为什么选择 EMA + 可穿戴设备？

1. **动态 (Dynamic)**：揭示情绪、症状与行为的波动轨迹。
2. **多维度 (Multi-dimensional)**：主观自评（EMA 问卷）结合客观生理（隐形设备无感监测）。
3. **情境相关 (Context-dependent)**：关联外部环境（噪音、社交、光线）与内部状态。
4. **真实世界 (Real-world)**：减少回忆偏差，提供高生态效度的数据支持。
