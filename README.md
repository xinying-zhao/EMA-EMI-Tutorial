# 生态瞬时评估（EMA）与生态瞬时干预（EMI）研究指南

欢迎来到 **EMA-EMI-Tutorial** ！本项目旨在为研究者提供一个开展生态瞬时评估与干预研究系统、实用的教程，介绍如何在精神心理、慢病管理等领域开展**生态瞬时评估（Ecological Momentary Assessment, EMA）与生态瞬时干预（Ecological Momentary Intervention）研究**。

## 🌟 项目简介

本项目以作者所作《"隐形"可穿戴设备联合生态瞬时评估方法在精神心理领域中的应用》主题报告内容为基础（中国设备管理协会精神心理物理诊疗学部成立大会暨中国医师协会神经调控专业委员会电休克与神经刺激学组第十届年会中，2024年11月23日），结合个人在博士后研究工作期间对EMA和EMI研究方法的学习和项目实践，为计划开展EMA/EMI研究实践的研究者提供经验分享。

## 📚 研究指南大纲

项目第一期聚焦EMA研究指南，根据EMA 研究步骤展开七大章节介绍，涵盖从研究问题确定到学术发表的完整生命周期。EMA 领域推荐阅读材料已并入引言章节。所有具体教程存放在 `tutorials/` 目录下，各章节涵盖理论背景、操作步骤、关键工具与参考文献等内容。

### 第二期：EMI 研究指南与进阶主题（规划中）

项目第二期按照研究开展的先后顺序，从 EMI 理论基础出发，依次经过干预设计、平台搭建、效果评估，最终落脚于多学科临床转化与前沿展望。以下为预计章节安排，内容持续更新中。

- 🧠 **[第八章：EMI 理论基础与干预类型](#)** - EMI 的概念演进、与 EMA 的关系、即时自适应干预（JITAI）等理论框架
- 🎨 **[第九章：干预内容设计与个性化策略](#)** - 行为改变理论、微干预设计原则、基于实时数据的个性化触发与内容适配
- ⚙️ **[第十章：干预平台选型与技术实现](#)** - 推送机制、EMA 数据驱动的实时触发引擎、多模态干预交付（文字/音频/视频）
- 📈 **[第十一章：干预效果评估与统计分析](#)** - EMI 专用 RCT 设计、N-of-1 试验、中介与调节效应分析、干预剂量-反应关系
- 🔄 **[第十二章：多学科临床转化与前沿展望](#)** - 精神心理、慢病管理、成瘾行为等领域的应用案例，AI 驱动的自适应评估与干预前沿（EMA/EMI 通用）
- 📖 **[推荐阅读与核心文献](#)** - EMI 与自适应干预领域的核心文献与推荐资源（筹备中）
