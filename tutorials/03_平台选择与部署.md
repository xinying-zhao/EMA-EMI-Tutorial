# 第三章：平台选择与部署

生态瞬时评估研究的数据采集由两类互补的数据流构成：一是受试者主动填答的主观自陈问卷（EMA），二是由设备被动采集的客观生理、行为与认知数据。两类数据对工具的能力要求截然不同，选型应遵循"**先明确能力需求，再考察具体平台与产品**"的路径：本章先梳理主观与客观数据采集各自需要的能力，再以清单对比市面主流的 EMA 研究平台与客观生理数据采集产品，供研究者对照选用。

## 3.1 平台能力需求

### 3.1.1 主观数据采集平台的能力需求

主观数据采集平台是承载 EMA 自陈问卷的软件系统，负责问卷的调度、提示推送、数据收集与导出。一个合格的 EMA 平台必须在受试者端（Participant app）与研究者端（Researcher dashboard）实现双向的无缝协同。Sahandi Far 等人（2025）总结了 EMA 应用应具备的核心能力：

- **评估逻辑配置**：支持时间表调度（Scheduling）、纳入/排除标准、输入验证、时间戳记录，以及评估数据的本地存储与安全传输。
- **提示与提醒机制**：能够向受试者推送调查提示并发送未完成提醒，研究者可通过在线仪表盘实时管理受试者、发送通知并监控数据质量。
- **触发能力**：支持时间触发（固定/随机/半随机调度）；若需要，还应支持事件触发，比如利用智能手机内嵌的 GPS、计步器、接近传感器，在特定活动或环境变化发生时自动弹出问卷。
- **跨平台一致性**：在 Android 与 iOS 上提供一致的用户体验与功能，避免因操作系统差异引入选择偏差。
- **离线与网络容错**：具备离线数据缓存能力，网络恢复后自动回传，以应对信号不稳定的场景。
- **隐私与合规**：遵循《通用数据保护条例》（GDPR）等数据保护法规，支持数据加密与安全传输。

### 3.1.2 客观数据采集的能力需求

客观数据采集由可穿戴设备或传感器被动记录生理、行为乃至认知数据，不依赖受试者主动填答，对受试者的配合要求更低，也更适合长期连续监测。其中，"隐形"可穿戴设备是近年发展最快、也最契合生态瞬时评估研究需求的一类产品形态。

Ling 等人（2020）在《Advanced Materials》的进展报告中指出，传统可穿戴设备"其实并不可穿戴"（Wearable is not wearable）：笨重坚硬的机身带来佩戴不适、运动伪迹与数据精度下降。以柔性材料和人体工学设计的第二代设备则实现了微型化与高舒适性的统一。与需要受试者每天多次主动点按的问卷不同，"隐形"可穿戴设备对受试者的负担更低，主要体现在四个方面：

- **物理无感**：设备轻薄、柔软、贴合，几乎感觉不到佩戴，不影响睡眠与日常活动，因此更易被长期连续佩戴。
- **被动采集**：数据由设备自动记录，受试者无需主动操作或反复填表，不打断日常生活节奏，也减少了主观报告的认知负荷。
- **降低病耻感**：外观隐蔽，不像医疗监测仪器般引人注目，可避免特殊人群（如精神心理疾病患者、职场人群）因佩戴医疗设备而产生的标签效应，提高长期参与意愿。
- **时间同步的客观锚点**：被动传感器自带高精度时间戳，为后续与主观 EMA 数据在统一时间轴上对齐提供了客观坐标。

据此，客观数据采集工具应具备以下能力：**连续被动采集**高精度的生理信号（如心率变异性、皮电活动、体动等）；**佩戴负担低**，可持续数天至数周；**自带高精度时间戳**，且可通过 API 或蓝牙低功耗（BLE）将数据流推送到 EMA 应用；**低维护成本**（长续航、易充电/更换）。此外，客观数据流还可包含认知维度：Moore 等人（2017）的系统综述表明，手机端的移动认知评估（如工作记忆、注意力任务）能够捕捉认知表现的个体内波动，且具有可接受的信度与效度。

## 3.2 市面平台与产品清单对比

### 3.2.2 客观生理数据采集产品

客观生理数据采集产品指以"隐形"可穿戴形态为主的硬件设备，用于被动采集心率变异性、皮电活动、体温、体动等生理信号。

## 3.3 多模态数据采集配置与时间戳同步操作步骤

实施主客观数据并行采集时，研究者需执行以下配置与对齐步骤：

- **步骤一：平台功能需求矩阵匹配**。在受试者端，确保主观平台具备高准度的通知推送能力及离线数据缓存功能；在研究者端，确认系统提供受试者分组管理、复杂的逻辑跳转配置以及标准化的 CSV/JSON 数据导出接口。若研究涉及传感器触发的事件型评估，还需确认平台支持相应的传感器接口（Sahandi Far et al., 2025）。
- **步骤二：硬件 API 接口对接**。评估所选可穿戴设备（如智能手环、皮肤贴片或智能戒指）是否开放数据接口（API）或支持蓝牙低功耗（BLE）直接将数据流推送到手机终端的 EMA 应用程序中。若设备为独立生态系统，需确认其数据能否导出并与 EMA 数据在统一时间轴上对齐（Colombo et al., 2019）。
- **步骤三：时间戳精确同步（Timestamp Synchronization）**。这是多模态研究中最关键的质控环节。必须通过系统级的时间服务器协议（NTP）对齐硬件传感器与手机系统的时间。确保当个体的皮电数据在下午 2 点 15 分 30 秒出现异常飙升时，系统能够精确匹配其在随后弹出的问卷中所报告的外部情境（如遭遇客户投诉或惊恐发作），从而建立起严密的心身因果推断链条。
- **步骤四：小规模技术预演（Technical pilot）**。在正式研究启动前，选择 3–5 名志愿者在真实生活场景中运行完整的多模态协议 2–3 天，检验设备的佩戴舒适性、蓝牙连接的稳定性、离线数据的缓存与回传，以及时间戳对齐的精度，并及时发现平台或硬件的隐性缺陷。

## 3.4 平台选型与部署的注意事项

**依从性衰减是平台选型的核心考量**。Sahandi Far 等人（2025）在一项针对新生儿父母人群的 JTrack-EMA+ 试点研究中发现，6 个月的平均依从率为 49.3%，从第一个月的 66.7% 显著下降至第六个月的 42%。这提醒研究者：长周期的多模态研究需内置依从性监控与干预机制（如阶段性提醒、研究者后台巡查），不能只依赖平台的技术功能。合理的依从性阈值高度依赖目标人群与协议强度，并无通用标准。

**主客观数据的融合需要刻意设计**。Colombo 等人（2019）在对 32 项 MDD 技术化 EMA 研究的系统综述中发现，仅 7 项在主观自评之外同时采集了生理测量。即便"隐形"可穿戴设备已大幅降低负担，"主客观融合"在多数已发表研究中仍是少数派，选择并部署客观数据采集设备本身就是一项需要刻意设计的研究决策。

**隐私与数据安全不可妥协**。多模态 EMA 同时采集主观自评、生理信号、位置与行为数据，属于高敏感个人数据。研究者应优先选择遵循 GDPR 等法规、通过官方应用商店分发、数据匿名化处理的开源平台，并确保数据传输链路加密。平台的开源属性（如 JTrack-EMA+、m-Path）还有助于审计其数据处理逻辑，降低"黑箱"风险。

**避免技术驱动的选择偏差**。若平台仅支持单一操作系统，将直接排斥另一系统的潜在受试者，引入选择偏差（Selection bias）。面向大众人群的研究，优先选择跨平台或提供等价双端应用的平台，以保证样本代表性。
